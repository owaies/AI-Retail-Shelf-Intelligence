# Contributing to AI-Retail-Shelf-Intelligence

Keep changes focused, verifiable, and compatible with the existing architecture.

## Workflow
1. Create a focused branch.
2. Reproduce the issue or define the expected behavior.
3. Make one coherent improvement at a time.
4. Run the available lint, build, tests, or validation checks.
5. Commit related changes with descriptive messages.

## Safety and quality
- Never commit secrets or local environment files.
- Avoid unrelated rewrites in focused fixes.
- Preserve existing data and authentication boundaries.
- Update docs when behavior or setup changes.

## Pull requests
Explain the problem, implementation, verification, and known limitations.
